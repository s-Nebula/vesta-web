Installing from an APK

Vesta is distributed as an APK file, outside Google Play. Android will ask for permission to install apps from unknown sources: grant it only to the browser or file manager you use, and remove it when you are done. Only download Vesta from this site and, if you want to verify the file, compare its SHA-256 fingerprint with the one published here.

For the parent or guardian

Vesta Parent

Manage profiles and linked phones, check location and safe zones, review reports, set up filters, study mode and limits, and answer the minor's requests.

Install it on the responsible adult's phone.

Installation

  1. 1Download the Vesta Parent APK on the responsible adult's phone.
  2. 2Open the file. If Android asks, allow “Install unknown apps” for the browser or file manager.
  3. 3Tap “Install” and open Vesta Parent.
  4. 4Create your account or sign in, and accept the current documents.
  5. 5Create the minor's profile: the linking QR code will appear.

For the minor's phone

Vesta Tracker

Links to Vesta Parent by scanning a QR code, sends the authorised information, applies the rules even offline, and lets the minor ask for permission or send an SOS alert.

Install it on the minor's phone or tablet.

Requirements

  • Android 7.0 or later (API 24).
  • An Internet connection.
  • A QR code or linking code generated in Vesta Parent.
  • Location, usage access, accessibility and local VPN permissions, depending on the authorised features.

Feature availability may vary by Android version and manufacturer.

Installation

  1. 1Download the Vesta Tracker APK on the minor's phone.
  2. 2Open the file and allow the installation if Android asks.
  3. 3Open Vesta Tracker and tap “Scan QR code”.
  4. 4Point at the code in Vesta Parent and grant the permissions for the features you will use.
  5. 5If needed, turn on usage access and the accessibility service in Android settings.

Do not install Vesta Tracker on a phone without informing its user and without the legally required authority and authorisations.
