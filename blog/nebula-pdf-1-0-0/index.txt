21:T944,<p>Nebula PDF 1.0.0 es la primera versión pública del traductor de PDF de Vesta Security. Es una <strong>beta</strong>: funciona y se puede usar todos los días, pero todavía es una compilación de pruebas y no la versión firmada de publicación.</p>
<h2>Qué incluye</h2>
<ul>
<li>Traducción de PDF del inglés al español <strong>conservando el diseño</strong>: imágenes, tablas, columnas, colores, títulos y numeración.</li>
<li><strong>Modo ciberseguridad</strong> con un glosario editable de más de 200 términos que no se traducen.</li>
<li><strong>Código y comandos intactos</strong>, y detección automática de IPs, URLs, rutas, CVE, técnicas de MITRE ATT&amp;CK y opciones de comandos.</li>
<li><strong>OCR</strong> para páginas escaneadas.</li>
<li>Traducción de <strong>libros largos</strong> en segundo plano, con notificación de progreso y botón para cancelar.</li>
<li><strong>Mis traducciones</strong>: la lista de todos los PDF traducidos, para abrirlos, compartirlos o borrarlos.</li>
<li><strong>Abrir con</strong> y <strong>Compartir</strong> desde el gestor de archivos, el navegador o el correo.</li>
</ul>
<p>Todo se hace en el teléfono. La app solo usa internet una vez, para descargar el modelo de idioma.</p>
<h2>Cómo instalarla</h2>
<ol>
<li>Descarga el APK desde la <a href="/aplicaciones/nebula-pdf/#descargar">página de Nebula PDF</a>.</li>
<li>Si quieres, verifica la huella SHA-256 del archivo con la que aparece en la página.</li>
<li>Ábrelo y permite la instalación de apps de origen desconocido cuando Android lo pida.</li>
</ol>
<p>Necesitas Android 8.0 o superior.</p>
<h2>Limitaciones conocidas</h2>
<ul>
<li>Las páginas giradas se dejan sin traducir.</li>
<li>Los PDF protegidos con contraseña de apertura no se pueden abrir.</li>
<li>Si una página tiene muy poco espacio libre, la letra traducida puede quedar algo más pequeña que la original.</li>
</ul>
<h2>El código</h2>
<p>Nebula PDF está escrito en Kotlin y su código está en <a href="https://github.com/s-Nebula/nebula-pdf" target="_blank" rel="noopener noreferrer">GitHub</a>. Si encuentras un error o un término técnico que se tradujo cuando no debía, escríbeme por <a href="https://wa.me/573246167956" target="_blank" rel="noopener noreferrer">WhatsApp</a> o por correo a <a href="mailto:nebulagnu@proton.me">nebulagnu@proton.me</a>.</p>
